Timing guide · What every setting does

All speech takes as long as your selected voice needs. The numbers below describe SILENT windows, not voice duration. A manual Repeat / Previous / Next action adds 2 seconds to the relevant pauses for that selected exercise.

SettingUsed inMeaning
Repetition windowsR, A, B, PLHow many silent repetition windows follow the English model spoken once. No transition beep; each window has its own end warning.
Pause per repetitionR, A, B, PLSeconds PER silent repetition window, not a combined total.
Active Recall answer timeAAfter the English cue, before the English model answer.
Polish → English recall pausePLAfter the Polish voice, before the English voice answers.
Business Response answer timeBAfter the English question, before the English model answer.
Quiet warningEvery silence/countdown in R, A, B and PLOne warning tone sounds this many seconds before EVERY pause ends. Never a start-of-counter sound. Set 0 for silence; if the requested offset cannot fit in a short pause, no sound is played.
Speech rateAllHow quickly the selected voice reads the cue/model; doesn't change the configured silence durations.

R: English sentence → repeat window 1 → ... → repeat window N → next sentence.

A: English cue → Active Recall answer time → English answer ONCE → N repetition windows.

B: English question → Business Response answer time → English model ONCE → N repetition windows.

PL: Polish sentence → Polish → English recall pause → English answer ONCE → N repetition windows.

Example: N=3, Pause per repetition=6.5s gives three separate 6.5-second windows (19.5s silent practice after the English model). It does NOT speak the model three times. Manual navigation adds 2 seconds to EACH applicable window.

Modes

R — Repeat: hear the English sentence, then repeat it during the silent windows.

A — Active Recall: hear a cue, answer from memory, then hear the target answer and repeat it.

B — Business Response: hear a business question, answer freely, then hear a model answer and repeat it.

PL — Translate & Recall: hear the Polish sentence (Polish voice), recall it in English during the configurable pause, hear the English answer (English voice), then repeat it. The same warning tone sounds before both kinds of pause end. Progress and Easy/Hard are tracked separately from R/A/B.

Polish translations are displayed below English in R/A/B. In PL mode, Polish appears above a smaller English translation. You can choose whether English is visible immediately or revealed after the recall pause.

Rounds: each mode keeps its own round and exact position. Closing or refreshing the app resumes the same place. A new round prioritizes the least-practised exercises.

Manual navigation: Repeat, Previous and Next immediately start continuous playback. The manually selected exercise gets 2 extra seconds in each answer/repetition window.

Headset controls: when supported by Android/browser, Play/Pause, Previous and Next media commands control the trainer. The app also plays a silent media carrier while training to improve headset routing and Android audio-focus behavior.

Easy / Hard: marks how difficult the currently displayed sentence felt. The app displays the last rating and its recorded date, highlights the last chosen button, and shows Easy/Hard totals per sentence. Older ratings have no exact date. Ratings do not increase the repetition counter.

Progress: local: your statistics are stored only in this browser. With server sync configured, the badge changes to a server/sync status.

Install app: installs the PWA on the current device. It appears only when the browser offers installation.
